# Product Context

## Why Huurly Exists
Huurly addresses the challenges in the Dutch rental market by providing a transparent, efficient platform that connects all stakeholders in the rental process. The platform reduces friction in property search, application, and management while ensuring compliance with Dutch rental regulations.

## Problems Solved
1. **Information Asymmetry**: Property owners and renters often lack clear information about each other's requirements and availability
2. **Complex Application Process**: Traditional rental applications involve multiple manual steps and paperwork
3. **Verification Challenges**: Ensuring tenant and property legitimacy is time-consuming
4. **Communication Gaps**: Poor communication between landlords, tenants, and property managers
5. **Regulatory Compliance**: Ensuring all parties follow Dutch rental laws and regulations

## How It Should Work
- **For Renters (Huurders)**: Easy property search with filters, streamlined application process, secure messaging, profile management
- **For Property Owners (Verhuurders)**: Property listing management, tenant screening, application review, lease management
- **For Property Managers (Beheerders)**: Multi-property oversight, tenant coordination, maintenance coordination
- **For Evaluators (Beoordelaars)**: Application assessment, compliance verification, recommendation system

## User Experience Goals
- **Intuitive Navigation**: Clear, role-based dashboards with logical information hierarchy
- **Efficient Workflows**: Minimize steps required for common tasks
- **Trust & Security**: Robust verification and secure data handling
- **Responsive Design**: Works seamlessly across devices
- **Accessibility**: Compliant with WCAG guidelines for inclusive design

## Current User Journey (Huurder Focus)
1. User registers/logs in as huurder
2. Completes profile setup
3. Searches for properties using filters
4. Views property details and applies
5. Communicates with property owners/managers
6. Manages applications and favorites
7. **NEW**: Access settings to update password, email, or delete account

## Settings Page Requirements
The instellingen page should provide users with:
- **Password Management**: Reset password functionality using existing modal
- **Email Updates**: Change email address with verification
- **Account Deletion**: Delete account with confirmation to prevent accidental deletion
- **Security**: All actions require proper authentication and confirmation
